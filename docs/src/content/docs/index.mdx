## What is included

<CardGrid>
	<Card title="A simple solver" icon="open-book">
		2D ideal MHD on a periodic grid: Rusanov fluxes, forward Euler, a projection for div B = 0. Only NumPy.
	</Card>
	<Card title="Test problems" icon="document">
		The Orszag-Tang vortex, the MHD rotor, a magnetized blast wave and a multi-fluid run, as executed notebooks.
	</Card>
	<Card title="Room to grow" icon="rocket">
		Higher-order reconstruction, HLL and HLLD fluxes, constrained transport: each a lesson with a check you can run.
	</Card>
</CardGrid>
