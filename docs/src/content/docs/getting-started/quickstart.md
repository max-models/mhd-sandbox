First, ensure that `mhd-sandbox` is [installed](/mhd-sandbox/getting-started/installation/).

## Basic usage

After installation, you can run the application with:

```bash
mhd-sandbox
```

which calls `mhd_sandbox.main.main` and prints a greeting.

## Use the package from Python

```python
from mhd_sandbox.main import main

main()
```

See the [API reference](/mhd-sandbox/api/mhd_sandbox/) for every module and function.
